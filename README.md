# AI-асистент аналітика

Лабораторна робота №4 з дисципліни "Методи та інструменти продуктової аналітики"

Виконала: Ткаченко Ганна Олексіївна, група ІК-32

## Опис

Це Jupyter-ноутбук із набором функцій, які допомагають аналітику швидше працювати з даними. Аналітик передає таблицю, метрику або питання звичайною мовою, асистент рахує потрібні показники в Pandas і передає їх мовній моделі Google Gemini. Модель пише висновки про якість даних, гіпотези, код Pandas або короткий текст для продакта.

Головне правило – усі числа рахує Pandas, а модель тільки пояснює їх. Після кожної відповіді асистент перевіряє, чи є числа з тексту моделі серед порахованих, чи існують колонки, про які вона пише, і чи безпечний код, який вона згенерувала.

## Функції

| Функція | Що робить |
|---|---|
| auto_eda(df, name) | Pandas рахує профіль таблиці (типи, пропуски, дублікати, формати записів, варіанти написання), модель пише висновки про якість даних |
| suggest_hypotheses(facts) | Pandas рахує 25 фактів по каналах, платформах, країнах і періодах, модель пропонує 5–8 гіпотез з посиланням на факти |
| ask(question) | Питання звичайною мовою, модель пише код Pandas, асистент показує код і виконує його. Якщо код падає, модель один раз виправляє помилку |
| explain_anomaly(metric, date) | Порівнює два періоди, рахує внесок кожного каналу, платформи і країни у зміну метрики і ділить зміну на ефект метрики та ефект структури. Модель формулює гіпотезу причини |
| executive_summary(metrics) | Короткий текст для продакта: що сталося, чому це важливо, що робити далі |
| check_numbers(text, source) | Моя власна функція: знаходить у відповіді моделі числа, яких немає серед порахованих |

Також у ноутбуці є порівняння першої і фінальної версій промптів: для кожної версії рахується, скільки чисел у відповіді не вдалося знайти в даних.

## Технології

- Python 3, Pandas, NumPy
- Google Gemini API, бібліотека google-genai, модель gemini-3.8-flash (запасні варіанти: gemini-flash-latest, gemini-flash-lite-latest)
- JSON mode (response_mime_type="application/json") для структурованих відповідей
- Google Colab

## Дані

Дані з лабораторної роботи №2, мобільний застосунок з підпискою (папка data/):
- users.csv – 4030 користувачів (дата реєстрації, країна, платформа, канал);
- events.csv – 42 420 подій (registration, open_app, view_content, start_trial, purchase та ін.);
- subscriptions.csv – 323 підписки.

Дані "брудні": різні формати дат, різне написання країн і платформ, дублікати. Тому на них добре видно, як працює EDA. Після 1 червня 2026 retention нових користувачів різко впав, і на цьому прикладі я перевіряю пояснення аномалій.

## Як запустити

1. Отримати безкоштовний API-ключ Gemini: https://aistudio.google.com → Get API key → Create API key.
2. Відкрити ai_analyst.ipynb у Google Colab (Файл → Завантажити блокнот).
3. Додати ключ: зліва значок ключа (Secrets) → Add new secret, Name: GEMINI_API_KEY, Value: ключ, увімкнути доступ для блокнота.
4. Завантажити в Colab файли users.csv, events.csv, subscriptions.csv з папки data/ (значок папки зліва → Upload). Можна завантажити і zip-архів з ними, ноутбук розпакує його сам.
5. Runtime → Run all.

Локально: pip install -r requirements.txt, задати змінну середовища GEMINI_API_KEY і запустити ноутбук з папки репозиторію.

Ключ не зберігається в коді і не потрапляє в репозиторій. На безкоштовному тарифі є ліміт запитів на хвилину, тому, якщо він спрацює або модель перевантажена, функція почекає 20 секунд і спробує ще раз.
